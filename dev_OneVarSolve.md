# New Branch dev_OneVarSolve

##  Goal: 

The goal of this method is a very efficient form of the solution which exploits a structure found in 
at least one 6-dof manipulator.  This structure is that the inverse kinematics becomes solvable if *one* 
of the unknowns were known.   If this situation is identified, the procedure is:

   1. Derive a fully symbolic solution to the remaining variables if the identified one were known.
   2. Use this solution in a 1-dimensional numerical search process which finds the value of the 
   "known-unknown" which produces a full solution which minimizes the error between the input pose and 
   the pose generated by the solution.
   
## Approach

The following paper describes this method for manual equation solution coupled with 1-d numerical searching:

Friedman, Diana CW, Tim Kowalewski, Radivoje Jovanovic, Jacob Rosen, and Blake Hannaford. "Freeing the serial mechanism designer from inverse kinematic solvability constraints." Applied Bionics and Biomechanics 7, no. 3 (2010): 209-216.

A PDF of this paper is in the directory IKBT/IKdocs.


The approach assumes that the full solution fails (befitting its position in the BT *after* the symbolic solution tree). 
One at a time, each unknown will be converted into a fixed parameter (keeping its same name)
and the symbolic solution will be tried again.  When an unknown is found which (when converted to 
a known) enables a full 
solution, we keep the symbolic expressions for each remaining now-solved unknown.
Sometimes multiple unknowns or even every unknown meets this condition.

The solution process then becomes

    1. Given a desired pose Td, assume the  unknown convereted to known is \theta_c.
    2. Choose an initial value for \theta_c compute error as:
        2.1 e = |Td-FK(T(\theta_c))
        2.2 find all values of \theta_c which minimize error using a 1D optimization method like golden section search. 
    3. Evaluate all joints at the minima found for \theta_c. 
    
This can be verified using the same closed loop methods that we developed for the symbolic and hybrid methods.
